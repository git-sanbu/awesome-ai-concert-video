## What AI Tiny Desk does

AI Tiny Desk is an independent browser-based creative studio for making desk-concert-style AI videos with 1–5 portrait assignments. Its selected reference has five fixed roles: lead vocalist, keyboard player, two backing performers and saxophone player. The workflow combines assigned portraits, a visual reference and a matching audio reference.

The site also publishes [portrait preparation guidance](https://aitinydesk.net/how-to-make-ai-tiny-desk), [role-mapping prompts](https://aitinydesk.net/prompts), [song and meme context](https://aitinydesk.net/tiny-desk-meme), and [tool comparisons by task](https://aitinydesk.net/ai-tiny-desk-tools).

Generation depends on provider availability and daily capacity. Identity consistency, reference-audio similarity and lip synchronization are not guaranteed. This repository publishes documentation and resource links; it does not distribute the website's application source or reference media.

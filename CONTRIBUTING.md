# Suggest a resource

Open an issue or pull request with the official URL, the task it helps with, a factual one-paragraph description and a link supporting any specific capability claim.

Disclose whether you own, work for, or receive compensation from the service. Do not submit affiliate links, copied marketing pages, fabricated benchmarks, star requirements or unsupported claims of free access.

We prefer distinct, useful workflows over many near-identical entries. Existing entries can be corrected or removed when their official information changes. Listing does not imply endorsement or a partnership.
